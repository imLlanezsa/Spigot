# 📦 CustomBukkit

A lightweight and flexible plugin API for Minecraft servers — built for developers, maintained by the community.  
Current maintainers: **Sakiio_** & **mathssw**

---

## 🌐 What is CustomBukkit?

**CustomBukkit** is a refined and community-driven implementation of the Bukkit API designed to support Minecraft plugin development in a clean and modular environment. It serves as a foundation for server software like Spigot and forks such as Paper, offering a well-documented interface to extend Minecraft gameplay.

## 🧪 Building the Project

This project is built with [Maven 3](https://maven.apache.org/), and requires Java 8 or higher. Follow these steps to compile from source:

```bash
# Clone the repo
git clone https://github.com/your-username/CustomBukkit.git
cd CustomBukkit

# Compile with Maven
mvn clean install
